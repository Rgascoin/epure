# À ajouter : la liste de travail

On dépile cette liste de haut en bas. Chaque catégorie est triée par priorité : d’abord ce qui est très cherché et de saison bientôt, ensuite les classiques, enfin les recettes plus pointues.

- `pnpm recipes:todo` coche tout seul les plats publiés (le dossier `content/recipes/<slug>/` existe) et les versions faciles écrites, puis affiche les prochains plats à faire.
- Pour écrire : [fiche mémo](recette-brief.md). Les `tags` indiqués nourrissent le calendrier (`lib/tags.ts`, `lib/collections.ts`).
- On ajoute librement des lignes ; le format est : ``- [ ] `slug` · **Nom** · tags · note``.
